# Cypress E2E - Juice Store

Esse projeto foi desenvolvido com o objetivo de apresentar como implementar testes automatizados utilizando o Cypress no site Juice Shop, além de executar os testes em um pipeline de CI/CD com GitHub Actions.

O Juice Shop foi definido como aplicação para os testes por ser um projeto leve, simples de configurar e com poucas dependências. Dessa forma, evita um nível elevado de complexidade e também reduz o consumo de memória durante a execução no pipeline do GitHub Actions, considerando as limitações de recursos disponíveis no plano gratuito.

O objetivo deste projeto é apresentar os principais recursos do Cypress e do GitHub Actions, demonstrando como essas ferramentas podem facilitar as atividades do dia a dia em testes automatizados e integração contínua.

Em breve, irei documentar mais detalhes sobre os cenários de testes, estrutura do projeto, funcionamento da automação e execução do CI/CD.
